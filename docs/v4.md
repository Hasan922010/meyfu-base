## 1. Buyurtma (zakaz) oqimi

To'g'ridan-to'g'ri sotuv (mavjud) saqlanadi. Yon oqim sifatida **buyurtma** qo'shildi:

```
  Agent / menejer / tarqatuvchi           Ombor                    Tarqatuvchi
  ────────────────────────────           ──────                    ───────────
  Buyurtma yozadi                 →   APPROVED buyurtmalar     →   Har buyurtma uchun
  (mijoz, tovar, kelishilgan          ro'yxatidan bir              yetkazilgan miqdorni
   narx, to'lov niyati)               tarqatuvchiga Loading         tasdiqlaydi
        │                              yig'adi                       │
        ▼                                  │                          ▼
   DRAFT → PLACED → APPROVED  ───────────► LOADED  ──────────────►  DELIVERED /
                                                                    PARTIALLY_DELIVERED
                                                                         │
                                                          shu yerda Sale yaratiladi
                                                          (Sale.order = buyurtma),
                                                          VanStock kamayadi
```

- **Bekor qilish:** istalgan ochiq holatdan (`DRAFT/PLACED/APPROVED/LOADED`), agar
  bo'yicha sotuv bo'lmagan bo'lsa.
- **Offline:** buyurtma yozish va yetkazish `bulk-sync` orqali oflayn ishlaydi
  (`order_create`, `order_fulfill` operatsiya turlari). `client_uuid` idempotent.

### Interfeys
- **Mobil (tarqatuvchi):** pastki menyuda «Zakaz» → *Yetkazishim* / *Olganlarim* tablari;
  «+ Yangi» — buyurtma yozish.
- **Admin:** *Buyurtmalar* bo'limi — ro'yxat + filtr, tasdiqlash/bekor, hamda
  «Yuklamaga yig'ish» (tarqatuvchi + ombor + belgilangan buyurtmalar → yuklama).

## 2. Ikki bosqichli maosh

Komissiya endi ikki qismdan iborat, ikkalasi ham `DistributorProfile` da sozlanadi
(Sozlamalar → Xodimlar → tarqatuvchi profili):

| Maydon | Ma'nosi |
|---|---|
| `order_commission_percent` | **Zakaz olgani** uchun foiz — buyurtmani kim olgan bo'lsa (yoki Order'siz to'g'ridan-to'g'ri sotuvda — sotuvchining o'zi) |
| `delivery_commission_percent` | **Yetkazgani** uchun foiz — `Sale.distributor` (yetkazuvchi) |
| `commission_percent` (eski) | Legacy — ikkala yangi foiz 0 bo'lsa, faqat yetkazishga qo'llanadi |
| `base_salary`, bonus, qo'lda tuzatish | O'zgarishsiz — alohida ish haqi shu yerda belgilanadi |

Bir odam ham zakaz olib, ham yetkazsa — **ikkala foizni ham oladi** (Payroll'da
ikkita alohida qator: `role=ORDER` va `role=DELIVERY`).

Standart foizlar (profil topilmasa): `Setting["payroll.default_order_commission"]`,
`Setting["payroll.default_delivery_commission"]`.

360° kartada va mobil «Mening maoshim» / «Mening hisobotim» da komissiya
`↳ zakaz olgani` / `↳ yetkazgani` bo'lib ajratib ko'rsatiladi.

## 3. Mahsulot rasmlari (galereya)

- Admin → Mahsulotlar → tahrirlash → **Rasmlar** bo'limi: bir nechta rasm yuklash,
  «Asosiy» belgilash, tartibni o'zgartirish (‹ ›), o'chirish.
- Birinchi yuklangan rasm avtomatik **asosiy** bo'ladi. Asosiy rasm `Product.image`
  bilan sinxron (eski kod shuni ishlatadi).
- Server rasmni qayta ishlaydi: asosiy max 1600px, eskiz max 320px (JPEG).
- Mobil katalogda (sotuv/buyurtma/mashina qoldig'i) tovar eskizi ko'rinadi —
  adashib ketmaslik uchun.

## 4. Kompaniya rekvizitlari · Muhr · PDF

### Sozlash
**Admin → Sozlamalar → «Kompaniya rekvizitlari»** (faqat SUPER_ADMIN tahrirlaydi):
nomi, STIR, manzil, telefon, bank rekvizitlari, rahbar F.I.SH., **logotip**,
**muhr** (PNG, shaffof fon tavsiya etiladi).

### Nakladnoy / yuklama PDF
Admin → Ombor → Tovar qabullari / Yuklamalar — har qatorda:
- **PDF** — pechatsiz
- **Pechat** — muhr imzo zonasida

PDF'da: kompaniya sarlavhasi, **tovar rasm eskizlari** jadvalda, jami/to'langan/qarz,
imzo bloki. Rasmi yo'q tovar — bo'sh katak (xato bermaydi).

### Mobil chek PDF (offline)
Mobil sotuv / yetkazish tugagach: **«PDF saqlash»** va **«Ulashish»** tugmalari.
- Chek 80mm termal uslubda, mobil qurilmada, **internetsiz** yaratiladi.
- «Ulashish» → WhatsApp/Telegram'ga fayl (Web Share); bo'lmasa — yuklab olish.
- Kompaniya rekvizitlari + muhr sinxronizatsiyada keshlanadi
  (`GET /company/public/`), >7 kun eskirsa ogohlantiriladi.
- Zakaz oluvchi «Olganlarim» ro'yxatidan **BUYURTMA** PDF'ini ham chiqara oladi.

### Shrift
PDF'lar `apps/core/fonts/DejaVuSans*.ttf` (kirill + lotin) bilan yasaladi —
o'zbek va rus matni to'g'ri chiqadi. Mobil chek uchun shu shriftning qisqartirilgan
varianti (`~52KB`) klientga yuklanadi.
